# Getting help

- **Questions about using a Kovir Labs tool:** ask in the [community forum Q&A](https://github.com/kovirlabs/community/discussions/categories/q-a).
- **Something is broken:** open a bug report in that project's repository.
- **An idea for a new tool:** post it in [Ideas](https://github.com/kovirlabs/community/discussions/categories/ideas).
- **A security problem:** see [SECURITY.md](SECURITY.md). Please don't post it publicly.
- **Anything else:** email [info@kovir.org](mailto:info@kovir.org) or visit [labs.kovir.org](https://labs.kovir.org).

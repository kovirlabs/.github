# Kovir Labs

**Open software for mission-driven work. Built once, useful to many organizations.**

Kovir Labs is the development arm of [Kovir LLC](https://kovir.org). We build tools that many mission-driven organizations can use, not custom software for just one. Everything here is open source and free for every organization to use.

🌐 [labs.kovir.org](https://labs.kovir.org) · 💡 [Suggest an idea](https://github.com/kovirlabs/community/discussions) · ✉️ [info@kovir.org](mailto:info@kovir.org)

## Officially supported

| Project | What it is | For |
| --- | --- | --- |
| [**Toril**](https://github.com/kovirlabs/toril) | A desktop Markdown editor that renders as you type and keeps your notes as plain files. Works with Obsidian vaults. | Writers, staff and teams who keep notes and documents in plain Markdown |
| [**Tenajlo**](https://github.com/kovirlabs/tenajlo) | A desktop Git client for self-hosted Forgejo, for people who'd rather not learn the command line. Git LFS built in. | Engineering and operations teams versioning code, PLC exports, CAD files and documents |
| [**Nu**](https://github.com/kovirlabs/nu) | A simple Python code editor for beginners, continuing the much-loved Mu editor. | Teachers, students and beginner programmers |
| [**TDS OpenAPI**](https://github.com/kovirlabs/tds-openapi) | A testable, machine-readable version of the TDS standard for booking trips across transit providers, with a conformance kit. | Transit agencies, demand-response and microtransit providers, and their vendors |
| [**Tag family**](https://github.com/kovirlabs/tagstack) | Small tools for plain semantic HTML that looks finished, behaves well, and is checked for mistakes. | Anyone writing web pages by hand or with an AI agent |

### The Tag family

- [**TagBrush.css**](https://github.com/kovirlabs/tagbrush): classless CSS. One `<link>` gives you layout, dark mode, forms and accessible colors.
- [**TagAction**](https://github.com/kovirlabs/tagaction): a tiny no-build script that adds sortable tables, copy buttons, dialogs and more. Pages still work with JavaScript off.
- [**TagCheck**](https://github.com/kovirlabs/tagcheck): finds semantic and accessibility mistakes in HTML, for people, CI and AI agents.
- [**TagKit**](https://github.com/kovirlabs/tagkit): copy-paste page templates, plus themes for [Jekyll](https://github.com/kovirlabs/tagkit-jekyll), [WordPress](https://github.com/kovirlabs/tagkit-wordpress), Pandoc, MkDocs and Hugo.

## How ideas become software

1. **Suggest.** Anyone can post a need on the [community forum](https://github.com/kovirlabs/community/discussions). Upvotes and comments show how widely it's felt.
2. **Kovir decides.** The kovir.org team chooses what Kovir Labs takes on, favoring needs that many organizations share.
3. **Labs builds and supports.** Accepted ideas become open-source tools, maintained by Kovir Labs.
